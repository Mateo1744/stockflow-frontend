# Capturas de StockFlow

Esta carpeta contiene cinco capturas reales de la aplicación integrada con datos de demostración ficticios:

1. `dashboard.png`: indicadores principales y estado del inventario.
2. `productos.png`: catálogo y filtros de productos.
3. `inventario.png`: existencias actuales por producto.
4. `ventas.png`: listado de ventas y sus estados.
5. `reportes.png`: indicadores y resumen gráfico calculados por la API.

Las imágenes no contienen credenciales, tokens ni configuraciones privadas. El README principal las enlaza mediante rutas relativas desde `docs/screenshots/`.
